触控区域

  • 华达州议会: button-primary在36px高度上配有20px的贴板.（原文参数：36px、20px）
  • 文本输入+文本区域 : 40px高处与12px贴板.（原文参数：40px、12px）
  • 标签条 : ~32–36px 高度; 延伸至 44px 内嵌式可切除细胞
  • 页脚链接 : 14px caption-md with line-height 2.0 + vertical padding (~44px tap row).

窄屏布局调整

  • 初等导航 : 桌面水平 → 平板- 窄汉堡抽屉。 下载行动按钮时保持可见.
  • 首屏TUI模拟: 通栏 以每响应式断点; ASCII 字标记比例缩放。
  • 标签条 : 如果标签溢出,则桌面固定宽的→移动水平滚动。
  • 页脚 : 5-up → 2-up 位于平板电脑 → 1-up 移动式.
  • /企业双栏: 50/50 desktop → vertical stack on tablet.
  • 区域编目 : 96px → 64px → 48px.
  • 首屏标题: 高尔夫球队: 38px → ~28px at mobile.
