触控区域

  • 华达州议会: button-primary和button-secondary在40px高度上配有16px的垫板.（原文参数：40px、16px）
  • 文本输入 : 36px高与12px垫板(仅AA下但AA以上).（原文参数：36px、12px）
  • 胶囊形 标签 : ~32–36px 延伸至 44px 可以通过垫子来抓
  • Doc-sidebar项目: 14px text + 32px line-height + 6px padding (~44px tap row).

窄屏布局调整

  • 初等导航 : 桌面水平集群 → 平板汉堡抽屉 768px. 黄行动按钮保持可见.
  • Sub-nav 条: 桌面水平锚行 → 平板电脑水平卷轴 → 移动式下拉.
  • 营销卡片: 4 列 → 3 列 → 2 列 → 1 列 1024, 768, 480px.
  • 定价网格 : 3 列 → 2+1 → 1- 堆积在平板和下面。
  • Doc 版式 : 240px侧边栏+720px条 →平板侧边栏手风琴 →移动完全崩溃.（原文参数：240px、720px）
  • 页脚 : 6-up → 3-up → 2-up. 腾讯网.
  • 区域编目 : 80px → 64px → 48px.
  • 首屏标题: 高尔夫球队: 36px → 28px 下方的响应式断点堆栈.
