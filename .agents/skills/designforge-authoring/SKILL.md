# DESIGN.md 与 HTML 样张编写规范

将 `DESIGN.md` 作为全站页面共用的设计依据，用 `preview.html` 展示这些规则组合后的视觉和操作效果。已有项目先读现行规范、相关组件文档及原始资料。根据任务只编辑对应交付物。新建时可参考同一套原创示例的 [DESIGN.md](assets/DESIGN.md) 和 [preview.html](assets/preview.html)。

## 写 DESIGN.md

- 用一段话交代整体风格、可观察特征和用途。规则写成能落地的指令，例如「主要按钮使用 `{colors.primary}`」，避免只写「有科技感」。
- 按项目需要记录颜色、字体、排版、间距、网格、圆角和层次。颜色写词元、色值和用途，字体写字号、字重、行高、字距及替代字体。组件引用同一组基础词元。
- 对相关组件记录结构、尺寸、默认和交互状态。区分悬停、按下、选中、焦点和禁用。响应式以具体断点和布局变化描述。已确认的动效记录触发时机、属性、时长、缓动和减少动态效果时的行为。
- 标注规则出处和已知缺口。未记录的颜色、状态或断点可以作为明确标注的演示设置。把示例产品文案、价格和账户数据标为演示。

## 校订中文稿

- 已有英文原件时，将中文独立交付为 `DESIGN.zh.md`。翻译标题、用途、状态说明和自然语言，保持英文原件可查。中文正文中的词元引用留在原有用途旁。
- 原样保留 CSS 属性、关键字、完整函数和声明、选择器、伪类、媒体条件、字体名及字体栈。按上下文判断表达，例如 CSS 值 `transparent` 保留，描述视觉效果时可写「透明背景」。
- 同样保留色值、数值、正负号、单位、范围、词元引用、链接目标及代码和配置。未加反引号的技术字面量也受保护。
- 批量处理时先锁定字面量，再按原文段落或表格行比较译前与译后。保持代码块、内联代码和 YAML 原值。遇到缺项、错位、乱码、重复或无法核实的译文，保留对应原文并在文档说明。重点人工检查字体名、属性和值的组合，以及组件与词元的对应关系。

## 制作 HTML 样张

编写和审查预览时，使用 [预览 HTML 编写与审查标准](../../../预览HTML编写与审查标准.md) 的逐格、逐卡、逐场景验收规则。

- 本插件的目录、详情和实时样张使用同一个风格名。已有样张的系统说明按归档翻译，原始标题可从资料来源查阅。原创样张可按「整页风格、基础词元、组件状态、组合场景」组织内容，导航链接到实际存在的章节。
- 将词元映射为 CSS 自定义属性。色块同时展示色值和用途，字号用真实文字呈现，间距、圆角和阴影应有可直接比较的试样。给组件提供实际状态或明确标注的静态状态。
- 选择适合风格的组合场景，例如预约、工作区或表格。演示操作只影响当前页面。已记录的明暗模式和响应式规则跟随规范，衍生模式或示意参数须标注。
- 先按产品用途确定平台类型，再编写页脚栏目和演示数据。共享模板应换成对应产品的内容。保留原有品牌场景、组件结构和有效链接，标明示例价格与账号数据。
- 要求离线时使用单页 HTML、内嵌 CSS 和少量原生 JavaScript。使用语义化控件，保留键盘焦点。窄屏布局根据规范收拢，宽表格可在自身容器内滚动。

## 交付前验收

- 对照 Markdown、页面和下载文件，核对颜色、字体名、CSS 属性、状态、断点、词元、原始代码和链接目标。批量归档时校验英文原件哈希。
- 在桌面和 `375px` 宽度检查标题、章节导航、试样和表格。验证键盘焦点及演示操作。声明支持离线时断网打开，检查字体回退和资源加载。
- 明确验证范围。区分全量自动检查、逐句校订和浏览器实测。
