# Design Composer — 交互与解析规范 M4-A

## 页面结构（低保真线框）

```text
┌──────────────────────────────────────────────────────────────┐
│ 方案名称 · 保存状态       撤销 重做  设备  对比  保存  导出 │
├──────────────┬──────────────────────────┬────────────────────┤
│ 搜索资源     │                          │ 当前维度 / 参数    │
│ 整体预设     │    真实 HTML 页面预览    │ 选项 / Tokens      │
│ 12 维度列表  │    Dashboard / 内容页面  │ 锁定 / 单维重置    │
│ 已选项 / 锁  │    独立 iframe          │ 兼容性诊断         │
├──────────────┴──────────────────────────┴────────────────────┤
│ 可折叠：设计配置 JSON / CSS / AI 提示词 / 导出记录           │
└──────────────────────────────────────────────────────────────┘
```

桌面三栏，可调整宽度；平板将属性栏变为抽屉，手机使用资源、预览、参数三个视图。预览设备至少 375/768/1440 CSS px；允许缩放但验收按真实 viewport。

## 操作流程

1. 新建方案：选页面类型和示范数据，可从预设或默认方案开始。
2. 单击维度，浏览候选并实时试用；显式应用后写入草稿历史，取消则回到原方案。
3. 参数编辑即时反馈；连续滑块操作合并为一次历史记录。支持单维重置、锁定、局部组件覆盖。
4. 套用整体预设前列出变更；锁定维度的选择和该维覆盖均保留。
5. A/B 对比复制当前配置为独立快照；同步 viewport 与示范数据，不同步待比较的样式。
6. 保存命名版本；未保存离开时提示。导出前校验配置、依赖与授权；导出与预览共用解析结果。

## 状态与数据

Draft：presetId、pageType、dimensionSelections、lockedDimensions、overrides、componentOverrides、resourceVersions、revision。
UIState：activeDimension、viewport、themeMode、compareSnapshot、dirty、diagnostics、history。
资源状态：loading、ready、empty、error、unavailable。预览失败显示原因及重试，不展示陈旧截图冒充更新。

## 解析引擎

默认值 → 风格预设 → 维度选择 → 用户参数 → 组件覆盖 → 校验 → ResolvedDesign → 渲染及导出。

锁定是套用预设时的操作约束，而非额外覆盖层；单维显式编辑可在解锁后进行。资源缺失应报告错误；引用版本固定。禁止直接执行第三方导入脚本。

| 规则 | 等级 | 处理 |
|---|---|---|
| 三栏布局与小屏空间不足 | warning | 建议折叠或抽屉 |
| 文本颜色对比度不足 | warning | 给出语义色修正候选 |
| 组件依赖缺失 | error | 阻止无效导出 |
| 数据展示与数据结构不符 | error | 切换适用模式或明确适配 |
| 玻璃材质背景影响可读性 | warning | 提高表面不透明度 |
| 动画与减弱动画设置冲突 | warning | 预览与导出均遵循系统偏好 |

## 验收用例

| ID | 操作 | 期望 |
|---|---|---|
| C01 | 仅切换色板 | 布局、业务数据、组件结构不变 |
| C02 | Bento + 玻璃 + 暖色 | 可同时渲染，无无效配置 |
| C03 | 锁定布局后切换预设 | 布局及其覆盖不变 |
| C04 | 修改圆角后撤销重做 | 预览与配置一致 |
| C05 | A/B 对比 | 相同数据、设备，不同方案 |
| C06 | 保存、重启、导入 | 资源版本及选择完整恢复 |
| C07 | 缺失依赖 | 明确诊断并阻止无效导出 |
| C08 | 导出 HTML/CSS/JSON | 同配置可复现，HTML 离线可用 |

此文是交互线框与行为规范；可运行 HTML 原型及真实页面实现属于后续交付，当前未完成。
