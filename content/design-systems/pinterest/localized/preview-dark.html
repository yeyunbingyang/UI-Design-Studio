触控区域

  • 华达州议会: button-primary 时 间 40px 高与高与高 14px 粘贴(~40×80px).
  • 搜索栏 : 48px高处.（原文参数：48px） 文本输入 : 44px.
  • 过滤芯片 : ~36–40px 延伸至 44px 可以通过垫子来抓
  • 图标循环按钮 : 40×40 配合 48×48 命中目标锁定

窄屏布局调整

  • 初等导航 : 桌面水平 → 平板汉堡抽屉。
  • 搜索栏 : 480px → 320px + 放大镜图标覆盖。
  • 平木工: 5–6 → 4 → 3 → 2 → 1 栏。
  • 模式 : centered ~480px → full-width sheet on mobile.
  • 区域编目 : 64px → 48px → 32px.
  • 首屏标题: 高尔夫球队: 70px → 56px → 44px → 36px.
  • 页脚 : 4-up → 2-up →手风琴.
