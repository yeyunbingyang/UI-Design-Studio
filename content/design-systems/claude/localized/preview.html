概览

暖纸色编辑风

Anthropic 采用偏暖的编辑式界面，以米白、珊瑚色和深海军蓝为三种主要色调。粗衬线体用于展示标题，人文主义无衬线体用于正文，深色代码预览卡呈现产品界面。

# Generate a thoughtful response
from anthropic import Anthropic

client = Anthropic()
message = client.messages.create(
    model="claude-opus-4",
    max_tokens=1024,
    messages=[{
        "role": "user",
        "content": "Hello, Claude"
    }]
)
