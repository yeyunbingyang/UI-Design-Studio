# Visual Assets & Effects / 视觉素材与特效

**ID:** visual-assets-effects

## Purpose / 用途
Define treatment and use of imagery, icons, illustration, media, backgrounds and static visual effects. Keep semantic icon behavior in Icons and static effects separate from time-based Motion.

定义图像、图标、插画、媒体、背景和静态视觉特效的处理方式。图标语义归入 Icons 维度；静态效果与随时间变化的 Motion 分开。

## Activation / 启用条件
Enable when identity depends on imagery, illustration, icon systems, gradients, textures, blur, glow, patterns or rich media.

当产品视觉识别依赖图片、插画、图标体系、渐变、纹理、模糊、发光、图案或富媒体时启用。

## Analysis checklist / 分析清单
- Icon family, stroke/fill, size, alignment, semantic mapping and accessible names.
- Image/illustration style, aspect ratio, crop, focal point, loading and fallback.
- Asset source, ownership, license and attribution.
- Background canvas, gradient, texture, pattern, blur, glow and layering.
- Performance and responsive behavior of media.

- 图标家族、线宽/填充、尺寸、对齐、语义映射和无障碍名称。
- 图片/插画风格、宽高比、裁切、焦点、加载和回退。
- 素材来源、权属、许可和归属。
- 页面背景、渐变、纹理、图案、模糊、发光和层叠。
- 媒体性能与响应式行为。

## Output contract / 输出契约
Provide asset categories, token mappings, allowed/forbidden treatments, aspect ratios, fallback behavior and provenance. Mark unknown rights as unverified and do not redistribute those assets.

输出素材分类、Token 映射、允许/禁止的处理、宽高比、回退行为和来源信息。权利未知标记为 unverified，不得再分发相关素材。

## Boundaries / 维度边界
Map imagery to imagery, icons to icons, page canvas to background, static visual treatment to effects. Duration/easing/transition rules belong to motion-feedback.
