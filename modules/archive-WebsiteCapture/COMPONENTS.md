# 网页采集实现

- React 前端使用同源本机 API。服务入口负责提供界面、预览、ZIP 与退出。
- Playwright 隔离上下文负责导航和滚动，Node.js 转发公开地址请求并收集资源。SQLite 保存任务和页面状态，页面文件写完后更新状态。
- 系统 DNS 优先。公开域名仅解析到 `198.18.0.0/15` 代理虚拟地址时会查询 Cloudflare HTTPS DNS，仍按真实公网地址校验和连接。本地域名及混合公网和非公网的结果继续拦截。
- 采集文件位于 `data/downloads/`，SQLite 使用宿主分配目录或独立运行时的 `data/`。分开备份 SQLite 和下载目录可保留完整档案。
- 站点预览按已完成页面即时合成。直接下载的 HTML 和 ZIP 根目录的 `index.html` 均内嵌页面、图片、样式及字体。预览的路由脚本负责站内切换，采集内容在禁用脚本的子窗口中渲染。`manifest.json` 记录页面、原始文件、状态和缺项。
- 初次运行由综合入口自检并按需安装。运行日志见独立菜单的 `.runtime/logs/` 或宿主管理日志。
- 站点扫描从入口、同源 Sitemap、手工路径和 DOM 链接发现页面。SQLite 保存队列、链接和发现来源，按链接深度编组并发，记录规则排除与超限。请求发出前逐跳检查同源及 robots 规则，普通资源仍受公网连接和大小校验。
- 页面就绪依据主体、DOM 静默、关键请求和字体信号，证据不足时保存部分结果。SQLite 迁移补充证据、来源和链接；旧记录根据既有缺项显示部分采集或未验证。重采在新目录完成后才切换数据库指针。
- 原稿保存每个状态的视口 DOM。比较使用同一 Chromium 在离线隔离页面生成截屏，`evidence.json` 包含状态、视口、样式映射、缺项和差异比例。HTML 和 ZIP 预览按页流式生成，打开后只解析当前页面的归档数据。预览仍只执行应用自身的离线路由脚本。
- 手动录制通过 Chrome 的本机 `DevToolsActivePort` 建立共享浏览器级 WebSocket，显式连接后再选择目标。独立 CDP 会话接收主框架可信点击、路由和资源事件。只有符合类型及公网范围的静态资源会读取响应正文，截图临时屏蔽表单控件与子框架。资源时间归因采用点击附近的请求开始时间。
- 录制按宿主数据目录分组，以原子写入的时间线文件保存。每次录制最多 30 分钟、200 步、40 个画面，原始静态资源总计最多 64 MiB。已有浏览器缓存中未再次请求的资源可能无法归档。结束时保留浏览器连接并释放标签页调试会话，插件退出时断开连接。
