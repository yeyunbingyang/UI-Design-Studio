# 网页采集插件需求

在 ToolOrbit 或 Windows 综合入口打开。输入公开网页地址，选择单页、同站快速采集或站点扫描。快速采集最多十页、两层链接。站点扫描默认为一百页、四层链接，同时采集最多两页，可降低页数与深度预算并添加同源路径。

任务结果区分完整、部分、未验证、失败、待采、规则排除和预算超限。中断后可继续，部分和失败页可重采。已取得的页面自动合并为一个站点预览。独立 HTML 断网可打开、切换已录制状态和跳转已采集链接。ZIP 包含原始脚本、DOM、分析和视觉对比。

站点扫描面向公开同源页面。状态录制在入口页上按顺序执行最多三次显式指定的操作。脚本依赖的持续交互由实际页面执行，离线档案切换已录制的画面。

手动录制复用用户授权的 Chrome 连接。用户选择现有的公开网页标签页并开始录制，结束后可逐步查看点击、页面跳转、截图和资源，或下载 HTML、ZIP。录制期间可以手动刷新补采资源，跨站跳转会自动结束录制。

验收以动态测试页、断网打开导出包、重启继续任务以及宿主内嵌启动为准。
